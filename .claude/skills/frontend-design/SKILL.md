# Frontend Design

Create interfaces that look intentionally designed rather than generated from a generic template.

## Core principles

- Prioritize visual hierarchy.
- Use a clear typography system.
- Use deliberate spacing.
- Use a consistent color system.
- Use strong composition.
- Avoid generic layouts.
- Avoid excessive rounded cards.
- Avoid unnecessary gradients.
- Avoid excessive glassmorphism.
- Avoid repetitive UI patterns.
- Do not make every section look like a separate card.
- Do not use visual effects without a purpose.

## Before coding

Inspect the existing project.

Identify:

- framework
- routing
- styling system
- components
- assets
- fonts
- existing design language

Do not replace the existing architecture unless necessary.

## Images

Prefer real project assets when available.

Do not replace existing images with placeholders unless explicitly requested.

If no assets exist, create the interface so real images can be inserted later.

## Responsive design

Design desktop and mobile together.

Do not simply shrink the desktop layout.

Think about:

- navigation
- typography
- spacing
- image cropping
- button sizes
- section order
- content density

## Implementation

Build reusable components where appropriate.

Keep components understandable.

Do not create unnecessary abstractions.

Do not modify unrelated parts of the project.

## Final check

Before finishing:

- inspect desktop layout
- inspect mobile layout
- check spacing
- check typography
- check buttons
- check image proportions
- check overflow
- check console errors

The final result should feel like a professional commercial website.
