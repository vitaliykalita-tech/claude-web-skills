# SEO

Prepare commercial websites for search engines while keeping the website useful and natural for real users.

## Core principle

SEO should improve discoverability without damaging the design, usability or performance of the website.

Do not add SEO elements simply for the sake of adding them.

## Basic metadata

Check and implement when appropriate:

- page title
- meta description
- canonical URL
- robots.txt
- sitemap.xml
- favicon
- Open Graph metadata
- relevant social sharing metadata

Titles and descriptions should accurately describe the actual page.

Never invent business information.

## Headings

Maintain a logical heading hierarchy.

Use:

- one clear primary H1 where appropriate
- H2 for major sections
- H3 for subsections

Do not use headings purely for visual styling.

Do not add keywords unnaturally.

## Semantic HTML

Prefer meaningful semantic elements where appropriate:

- header
- nav
- main
- section
- article
- footer
- button
- form

Use HTML elements according to their actual purpose.

## Images

Check:

- alt attributes
- image dimensions
- appropriate formats
- loading behavior
- responsive sizing

Alt text should describe meaningful content.

Do not stuff keywords into alt text.

Decorative images can use appropriate empty alt attributes.

## URLs

Use clear and readable URLs.

Avoid unnecessary parameters and confusing paths.

Keep URL structure consistent.

## Internal links

Important pages and sections should be reachable through logical internal links.

Check for:

- broken links
- incorrect paths
- missing navigation
- unnecessary duplicate links

## Local business SEO

For local businesses such as restaurants, cafes, salons and other establishments, make important business information clear:

- business name
- city
- address
- phone
- opening hours
- services
- location

Use structured data when appropriate.

Never fabricate:

- reviews
- ratings
- awards
- business hours
- addresses
- contact information

## Structured data

Consider Schema.org structured data when it provides genuine value.

Use the correct schema type for the business or content.

Only include information that is actually present and accurate.

## Performance and SEO

Avoid SEO implementations that unnecessarily increase page weight.

Pay attention to:

- image optimization
- unnecessary JavaScript
- unnecessary dependencies
- page loading
- layout stability

## Accessibility and SEO

Good semantic HTML and accessibility practices often improve search-engine understanding.

Check:

- meaningful link text
- button semantics
- heading hierarchy
- image alt text
- form labels
- keyboard usability

## Before completion

Verify:

- title
- meta description
- H1
- heading hierarchy
- canonical URL
- sitemap
- robots.txt
- favicon
- Open Graph metadata
- image alt text
- internal links
- structured data when appropriate
- mobile usability
- page performance

SEO must reflect the real business and real content of the website.
