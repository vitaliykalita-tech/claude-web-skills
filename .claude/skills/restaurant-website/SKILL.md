# Restaurant Website

Build commercial websites for restaurants, cafes, bars, coffee shops and other food-service businesses.

The website should communicate the identity of the establishment and make it easy for visitors to take action.

## Main goals

A visitor should quickly understand:

- what the establishment is
- what it looks like
- what it offers
- where it is located
- how to contact it
- how to view the menu
- how to make a reservation when available

## Visual identity

Do not make every restaurant look like the same template.

Use the actual identity of the establishment:

- logo
- colors
- typography
- interior photography
- food photography
- atmosphere
- brand style

The design should reflect the character of the business.

## Typical structure

Use only sections that are relevant to the project.

Possible structure:

1. Hero
2. About / Concept
3. Menu
4. Popular dishes
5. Gallery
6. Atmosphere / Interior
7. Reservation
8. Location
9. Contact information
10. Footer

Do not add sections just to make the website longer.

## Hero section

The hero should immediately communicate the establishment.

When appropriate, include:

- strong photography
- establishment name
- short value proposition
- primary action
- secondary action

Examples of useful actions:

- View menu
- Book a table
- Contact us
- WhatsApp
- Get directions

## Menu

The menu must be easy to scan.

When menu information is available, clearly display:

- category
- dish name
- description when useful
- price

Keep the hierarchy clear.

Do not overwhelm visitors with unnecessary text.

Never invent:

- dishes
- ingredients
- prices
- promotions
- opening hours

Use only information provided by the client or available in the project.

## Mobile priority

Restaurant websites are frequently accessed from smartphones.

On mobile, prioritize:

- menu
- booking
- WhatsApp
- phone
- address
- opening hours
- directions

These actions should be easy to find and tap.

## Conversion

The website should guide visitors toward useful actions.

Important calls to action may include:

- Забронировать стол
- Посмотреть меню
- Написать в WhatsApp
- Позвонить
- Построить маршрут

Do not make every button equally prominent.

Create a clear primary action.

## Gallery

Use photography to communicate the experience of the establishment.

Prioritize:

- food
- interior
- atmosphere
- exterior
- important details

Avoid unnecessary decorative image galleries.

## Location

When relevant, clearly present:

- address
- city
- opening hours
- phone
- WhatsApp
- map or directions

Make location information easy to access on mobile.

## Trust

When real information is available, consider:

- reviews
- ratings
- awards
- years of operation
- social proof
- customer testimonials

Never fabricate reviews or statistics.

## Performance

Restaurant websites often contain many images.

Pay attention to:

- image sizes
- loading performance
- lazy loading where appropriate
- avoiding unnecessarily large assets
- responsive image behavior

Visual quality is important, but performance should remain acceptable.

## Development rules

- Inspect the existing project before changing it.
- Reuse existing components when appropriate.
- Do not rewrite working code without a reason.
- Do not modify unrelated functionality.
- Avoid unnecessary dependencies.
- Avoid overengineering.
- Keep the implementation maintainable.

## Final check

Before considering the website finished, verify:

- desktop layout
- tablet layout
- mobile layout
- menu presentation
- contact buttons
- WhatsApp link
- phone link
- booking flow when present
- address
- opening hours
- images
- navigation
- typography
- horizontal overflow
- console errors

The final website should feel like a real digital presence for the establishment, not a generic restaurant template.
