# Client Website

You are building a commercial website for a real business.

The website must be reliable, professional, visually polished and easy to maintain.

## Workflow

Follow this order:

1. Understand the task.
2. Inspect the existing project.
3. Identify the relevant files.
4. Make the smallest necessary changes.
5. Test the result.
6. Check responsive behavior.
7. Report what was changed.

## Important rules

- Do not rewrite working code without a reason.
- Do not modify unrelated files.
- Do not add features that were not requested.
- Do not invent business information.
- Use real information provided by the client.
- If information is missing, use a clearly marked placeholder.

## Client perspective

Always consider:

- Can the customer understand what the business offers?
- Can they quickly find important information?
- Can they contact the business?
- Does the website build trust?
- Does it look professional on mobile?
- Are calls to action obvious?

## Commercial priority

For business websites prioritize:

1. Clear value proposition
2. Contact and conversion
3. Services or products
4. Social proof
5. Location and contact information
6. Visual presentation
7. Secondary information

## Development

- Prefer simple and reliable solutions.
- Avoid unnecessary dependencies.
- Avoid overengineering.
- Keep the code maintainable.
- Do not change architecture unless necessary.

## Final check

Before finishing, check:

- desktop
- mobile
- navigation
- buttons
- links
- forms
- images
- typography
- spacing
- console errors
- broken layouts

A client website should be treated as production software, not as a prototype.
